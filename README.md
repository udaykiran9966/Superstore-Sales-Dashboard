# Superstore Sales Dashboard

Interactive sales dashboard built in Power BI using the Superstore dataset.

## Tools
Power BI, DAX, Excel

## KPIs
- Total Sales: 2.29M
- Total Profit: 286.40K
- Profit Margin: 12.5%
- Total Orders: 5K
- Average Order Value: $458

## Key Insights
- Sales are highest in Sep, Nov and Dec, and lowest in Feb
- Sales grew 29.6% in 2016 and 20.4% in 2017
- Filters: Year and Region slicers
